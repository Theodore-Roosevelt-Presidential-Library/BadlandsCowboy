# Bad Lands Cow Boy holdings log

Which institutions have been checked for copies of the Cow Boy, and what they hold. Check this before asking anyone for scans so the same dead ends aren't searched twice. Add a row whenever an institution answers, including when the answer is "nothing new."

For items recovered from other papers' reprints, see `reprints/search_log.md`.

## Base run

| Holder | What it is | Notes |
|---|---|---|
| State Historical Society of North Dakota | Microfilm of the surviving run | Source of the Library of Congress (Chronicling America, LCCN sn84024777) scans the site uses. 20 weeks missing; Nov. 25, 1886 partial. |
| Library of Congress, Chronicling America | Digitized SHSND film, ~4,700 px wide | The master images for the site. |

| 2026-10-16 | Montana Historical Society | Nov. 25, 1886 (missing page 3 and the rest of page 2) | **Nothing new.** They sent two scans: page 1 and the page 2/page 4 composite.
